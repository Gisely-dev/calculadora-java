# Calculadora em Java

Calculadora desenvolvida em Java para praticar os conceitos básicos de Programação Orientada a Objetos (POO). O projeto permite realizar operações matemáticas básicas por meio de um menu interativo no terminal.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Tratamento de divisão por zero
- Menu interativo no terminal

## Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos (POO)

## Estrutura do Projeto

```text
├── Principal.java
├── Calculadora.java
└── README.md
```

## Como Executar

1. Clone este repositório.
2. Compile os arquivos `.java`.
3. Execute a classe `Principal`.
4. Escolha a operação desejada e informe os valores.

## Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais da linguagem Java, como criação de classes, objetos, métodos, estruturas de decisão, laços de repetição e tratamento de exceções.

## Autor

Projeto desenvolvido para fins acadêmicos e de aprendizagem em Java.
